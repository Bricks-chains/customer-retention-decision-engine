# Stage 2 - Exploratory analytics

The analysis should answer business questions before modeling:

- Is churn concentrated among month-to-month customers?
- Do tenure and contract length change risk materially?
- Which payment methods or service combinations correlate with churn?
- Where are missing numeric values concentrated?

Recommended outputs are a data-quality summary, churn-rate table by key segments, and a small set of decision-oriented charts. Every chart should state the denominator and avoid implying causation from correlation.
